# PLAN C · خريطة أحياء الرياض التفاعلية

## التشغيل
- افتح `index.html` في متصفح حديث (Chrome / Safari / Edge). لا تحتاج إلى تثبيت أي حزم أو بدء خادم.
- تعمل الخريطة بحدود مبسطة مضمّنة داخل ملف HTML عند عدم توفر الإنترنت.
- عند الاتصال بالإنترنت، تحاول الصفحة استخدام ملف GeoJSON الأصلي لعرض حدود أكثر تفصيلًا، وتحاول كذلك جلب تقديرات سكانية منشورة لعام 2021 لبعض الأحياء.
- قد تمنع إعدادات الشبكة تحميل المصادر الخارجية أو Google Fonts؛ سيستمر الموقع بالعمل باستخدام حدوده وخطوطه البديلة.

## التفاعل
- **نقرة واحدة:** تمييز الحي المختار بالبرتقالي. جميع الأحياء الأخرى تبقى بلون موحد، دون تلوين مناطق الرياض.
- **نقرتان:** فتح لوحة معلومات الحي.
- **الهاتف:** يمكن لمس الحي، ثم استخدام زر «تفاصيل الحي».
- **البحث:** كتابة اسم أي حي موجود في البيانات، ثم اختياره للانتقال إليه.
- **التكبير والتصغير:** أزرار `+` و`−` أو عجلة الفأرة؛ التحريك بالسحب.
- **التصدير:** زر «تصدير المحدد» يُنشئ صف CSV للحي المحدد.

## مصادر الحدود ودقتها
- المصدر العام: https://github.com/i1s1i/GIS-rcrc-map
- البيانات الأصلية: https://raw.githubusercontent.com/i1s1i/GIS-rcrc-map/main/data/riyadh_districts.geojson
- يتضمن هذا الإصدار **145 مضلعًا** لأحياء الرياض، وهو **ليس مجموعة كاملة أو رسمية لكل أحياء المدينة**؛ مثلًا بعض الأحياء الأحدث غير ممثلة.
- نسخة الاستعادة دون إنترنت ناتجة عن تبسيط هندسي RDP بعتبة تقريبية 0.0005 درجة (عشرات الأمتار). تنزاح بعض الزوايا قليلًا نتيجة التبسيط؛ **لا تستخدمها للمساحة القانونية أو حدود الملكية**.
- عند نجاح تحميل الملف الأصلي، تستعمل الصفحة نقاط الهندسة الأصلية بدل النسخة المبسطة.
- مساحة الحي الناتجة من حساب هندسي تقريبي على الإحداثيات؛ ليست مساحة هندسية معتمدة.
- للتحقق من حدود الحي الرسمية: https://rmp.alriyadh.gov.sa/ar/gis-portal

## البيانات السكانية والتجارية
- لا تُولّد الأرقام الديموغرافية ولا عدد المنشآت بشكل عشوائي أو بالاعتماد على المساحة.
- تحاول الصفحة قراءة حقل `sum_population_per_point2021` من طبقة ArcGIS منشورة، إن كان متاحًا، وتعرضه **كتقدير تجميعي لعام 2021 وغير رسمي**. لا تعتبره تعدادًا رسميًا أو بيانات سكان حي حديثة.
- المصدر الاختياري لبيانات 2021: https://services7.arcgis.com/co15Y7Q02mBEZqnK/ArcGIS/rest/services/Riyadh_Metro_WebMapv2_WFL1/FeatureServer/0
- مرجع المقارنة على مستوى **المدينة فقط**: أمانة الرياض، 47.8% سعوديين و52.2% غير سعوديين — https://rmp.alriyadh.gov.sa/ar/riyadh-in-numbers . **هذه النسب لا تطبّق على كل حي.**
- معلومات السجلات التجارية/واجهات الاستعلام: https://mc.gov.sa/ar/About/Statistics/Pages/GISInfo.aspx
- مسح الرياض الديموغرافي لعام 2026 يغطي أكثر من 217 حيًا، ما يؤكد نقص تغطية مجموعة الحدود الحالية: https://www.spa.gov.sa/N2548194

## استيراد ملف إحصاءات موثوق
1. افتح `neighborhood_stats_template.csv` في Excel أو Google Sheets، واترك رؤوس الأعمدة بدون تغيير.
2. املأ كل حي تتوفر له بيانات بمؤشرات رقمية ومصدر واضح وسنة البيانات؛ لا تخمّن القيم المفقودة.
3. من الصفحة اختر «استيراد إحصاءات الأحياء CSV» لعرضها داخل لوحات المعلومات. تظل البيانات محلية في المتصفح ولا تُرسل إلى أي خادم بواسطة ميزة الاستيراد.

الأعمدة:

| العمود | المعنى |
|---|---|
| `name_ar` | اسم الحي بالعربية، مطابق للاسم في الخريطة |
| `population_estimate` | إجمالي السكان أو التقدير |
| `saudi_pct` | نسبة السعوديين من 0 إلى 100 |
| `non_saudi_pct` | نسبة غير السعوديين من 0 إلى 100 |
| `commercial_count` | عدد المنشآت/السجلات حسب تعريف المصدر |
| `source` | اسم جهة البيانات أو عنوان المصدر (إجباري للعرض) |
| `year` | سنة البيانات (إجباري للعرض) |
| `method` | طريقة الحساب أو نوع التقدير |

الصفوف بدون `source` و`year` تُستبعد، وكذلك الصفوف التي تحتوي نسبتين لا يتقارب مجموعهما مع 100%. القيم الناقصة تظهر «—»، لا صفرًا.

## ملفات المشروع
- `index.html`: واجهة متكاملة متجاوبة، JavaScript/CSS/SVG، بدون تبعيات برمجية خارجية إجبارية.
- `districts.compact.txt`: هندسة مبسطة مضغوطة من حدود الأحياء.
- `neighborhood_stats_template.csv`: قالب إدخال مؤشرات الأحياء.
- `plan-c-mark.svg`: علامة PLAN C مستخرجة من مرجع الهوية المرفق من المستخدم. مضمّنة داخل `index.html` أيضًا.
- `build_page.py`: مصدر توليد ملف HTML من الهندسة والشعار، لإعادة البناء أو التطوير.
- `preview_desktop.png` و`preview_mobile.png`: لقطات معاينة.

## الهوية البصرية
استُخدمت قيم من لوحة إلهام PLAN C المرفقة: #FE5000، #001E60، #6CACE4، الأسود/النيلي، الحواف المشطوفة، ومساحات الهدوء البصري، مع خط IBM Plex Sans Arabic وChakra Petch وIBM Plex Mono عند توفرها عبر Google Fonts.

## حقوق المصادر
البيانات الجغرافية المفتوحة تتطلب الالتزام بتراخيص مصادرها والاحتفاظ بنسب المصدر. تحقّق من شروط إعادة النشر والترخيص في المستودع الأصلي وعند مزجها مع مصادر GIS الأخرى. الشعار والهوية مواد مرفقة من صاحب المشروع.
